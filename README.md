# SIA 2 Activities

## Activity 1 – Design and Development of a Web-Based Mantilla Funeral Reservation System
Developed a comprehensive system architecture for digitizing funeral service bookings. This activity included creating use case diagrams, planning the reservation workflow, and designing the interaction between the client-side reservation portal and the administrative management backend.

## Activity 2 – Laravel Mini System (ML Hero System)
Developed a mini-system using the Laravel framework that serves as a dynamic encyclopedia for game characters. The application features a responsive user interface for displaying hero roles, abilities, playstyles, and character details.

## Activity 3 – Laravel CRUD System with Database
Created a full-stack CRUD (Create, Read, Update, Delete) application using Laravel and database integration. The system enables users to manage academic responsibilities through a centralized dashboard with data management functionalities.

## Activity 4 – Laravel Form Handling & Validation
Implemented server-side form handling and validation using Laravel. The system collects and validates user input through different form components while ensuring secure and accurate data processing.

## Activity 5 – Building and Integrating a Laravel Application with APIs
Integrated third-party APIs into a Laravel application to fetch and display real-time environmental data for selected locations. This activity demonstrated API consumption, data handling, and frontend presentation.

## Final Project – "Design and Development of a Web-Based Mantilla Funeral Reservation System"
The final project is a web-based platform designed to make funeral service reservations more organized, accessible, and efficient. it allows clients to view available services, submit reservation requests, and communicate booking details, while helping administrators manage reservations, client information, and service records through a centralized system.
